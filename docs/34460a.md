## `k34460a`

Keysight 34460A DMM subcommands

```console
$ egse k34460a [OPTIONS] COMMAND [ARGS]...
```

**Options**:

**Commands**:

* `about`: Show information about the connected DMM
* `measure`: Measure the DC voltage on the DMM.

### `k34460a measure`

Measure the DC voltage on the DMM.

**Usage**:

```console
$ egse k34460a measure [OPTIONS] TYPE:{vdc} RANGE
```

**Arguments**:

* `TYPE:{vdc}`: Function to measure  [required]
* `RANGE`: Range to measure (auto, 0.1, 1, 10, 100, or 1000)  [required]

**Options**:

* `--help`: Show this message and exit.
