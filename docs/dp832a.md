## `dp832a`

Rigol DP832/A power supply subcommands

**Usage**:

```console
$ egse dp832a [OPTIONS] IP COMMAND [ARGS]...
```

**Arguments**:

* `IP`: IP address of the DP832A  [required]

**Options**:

* `--unsafe`: Initialize the power supply without resetting outputs
* `--help`: Show this message and exit.

**Commands**:

* `about`: Show information about the connected power...
* `status`: Show status of all channels
* `query`: Manually send a command to the power supply
* `ch`: Channel-specific commands

### `dp832a about`

Show information about the connected power supply

**Usage**:

```console
$ egse dp832a about [OPTIONS]
```

**Options**:

* `--help`: Show this message and exit.

### `dp832a status`

Show status of all channels

**Usage**:

```console
$ egse dp832a status [OPTIONS]
```

**Options**:

* `--help`: Show this message and exit.

### `dp832a query`

Manually send a command to the power supply

**Usage**:

```console
$ egse dp832a query [OPTIONS] COMMAND
```

**Arguments**:

* `COMMAND`: SCPI command  [required]

**Options**:

* `--help`: Show this message and exit.

### `dp832a ch`

Channel-specific commands

**Usage**:

```console
$ egse dp832a ch [OPTIONS] CHANNEL COMMAND [ARGS]...
```

**Arguments**:

* `CHANNEL`: Channel to modify (1, 2, or 3)  [required]

**Options**:

* `--help`: Show this message and exit.

**Commands**:

* `on`: Turn the channel output on
* `off`: Turn the channel output off
* `set`: Set the output voltage or current, or the...
* `get`: Get the measured voltage or current, or...
* `mode`: Get the channel&#x27;s mode of operation.

#### `dp832a ch on`

Turn the channel output on

**Usage**:

```console
$ egse dp832a ch on [OPTIONS]
```

**Options**:

* `--help`: Show this message and exit.

#### `dp832a ch off`

Turn the channel output off

**Usage**:

```console
$ egse dp832a ch off [OPTIONS]
```

**Options**:

* `--help`: Show this message and exit.

#### `dp832a ch set`

Set the output voltage or current, or the OCP or OVP limit on the channel.

**Usage**:

```console
$ egse dp832a ch set [OPTIONS] TYPE:{voltage|current|ovp|ocp} VALUE
```

**Arguments**:

* `TYPE:{voltage|current|ovp|ocp}`: Function to set  [required]
* `VALUE`: Value to set in mV/mA  [required]

**Options**:

* `--help`: Show this message and exit.

#### `dp832a ch get`

Get the measured voltage or current, or the set OVP or OCP values on the channel.

**Usage**:

```console
$ egse dp832a ch get [OPTIONS] TYPE:{voltage|current|ovp|ocp}
```

**Arguments**:

* `TYPE:{voltage|current|ovp|ocp}`: Function to get  [required]

**Options**:

* `--help`: Show this message and exit.

#### `dp832a ch mode`

Get the channel&#x27;s mode of operation.

**Usage**:

```console
$ egse dp832a ch mode [OPTIONS]
```

**Options**:

* `--help`: Show this message and exit.
